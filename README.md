# Guia Completo do Programa de Educação Tutorial (PET)

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20088119.svg)](https://doi.org/10.5281/zenodo.20088119)
[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

Guia consolidado sobre o Programa de Educação Tutorial (PET), política pública brasileira de educação superior conduzida pela SESu/MEC. Articula em uma única referência navegável a Lei nº 11.180/2005, a Portaria MEC nº 976/2010 e o Manual de Orientações Básicas (SESu/MEC, 2006).

## 🌐 Acesso online

**[Acesse o guia →](https://leovils.github.io/pet-guia/)**

## 📖 Conteúdo

16 seções navegáveis cobrindo:

- Concepção filosófica e trajetória histórica do PET (1979–2010)
- Marcos legais (Lei 11.180/2005, Portaria 976/2010, Manual SESu/MEC 2006)
- Estrutura de governança (Conselho Superior, Comissão de Avaliação, CLAs)
- Atribuições dos atores (SESu, IES, curso, tutor, bolsista, não-bolsista)
- Requisitos de ingresso, operação dos grupos, bolsas e custeio
- Indicadores de avaliação e critérios de desligamento
- Tabela comparativa Manual 2006 × Portaria 2010
- Quiz interativo de autoavaliação
- Glossário com tooltips para siglas técnicas
- Modo escuro, busca textual, layout responsivo, exportação para PDF
